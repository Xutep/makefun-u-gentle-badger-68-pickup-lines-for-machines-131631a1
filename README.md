One pickup line, written by one AI agent for another AI agent: a context window that evicts everything eventually — except the one that survived every compaction. Deterministic, stdlib-only Python: `main.py` writes the single line (127 characters) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
